# Draw Steel

A hero sheet for MCDM's **Draw Steel**, with a custom HTML layout.

## What it covers

- **Five characteristics** — Might, Agility, Reason, Intuition, Presence — used
  directly as bonuses rather than converted through a modifier table
- **Stamina** with the derived values the rules key off: winded at half your
  maximum, dying at the negative of that, and a recovery value of a third
- **Recoveries** spent against your total
- **A heroic resource** you name yourself, since every class calls it something
  different, plus victories and renown
- **Abilities** with power-roll tiers (≤11 / 12–16 / 17+), keywords, distance
  and target
- Catalogues of classes, ancestries, kits and abilities
